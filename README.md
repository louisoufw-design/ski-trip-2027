# 雪國手帖：2027 三月滑雪計畫

兩個滑雪初學者，2027 年 3 月從**大阪**出發去日本滑雪。還沒決定去哪座雪場，所以做了這個網站，讓同行的人可以一起比較、一起決定。

網站採日系旅遊雜誌風格，共 10 個分頁：

| # | 分頁 | 內容 |
|---|------|------|
| 01 | 精選雪場 | 北海道與本州的差別、4 座精選雪場、8 座雪場名鑑（附 Google 地圖連結）與並排比較表 |
| 02 | 三月雪報 | 8 座雪場在三月上、中、下旬的雪況 |
| 03 | 條件評分 | 拉動 7 個條件的權重，即時算出每座雪場的 100 分制分數與排名 |
| 04 | 交通 | 從大阪到各雪場的走法、時間、票價，以及相關周遊券划不划算 |
| 05 | 住宿戰略 | 8 座雪場「住雪場旁」與「住遠一點通勤」的費用與時間比較 |
| 06 | 旅費帳本 | 選 2–3 座雪場並排試算每人花費，可各自選交通、住宿、課程類型 |
| 07 | 選板研究室 | 雙板 vs 單板比較、三題小測驗、扁平足建議 |
| 08 | 教練課 | 初學者通常上幾天、半天或全天，以及有中文教練的雪校與價格 |
| 09 | 季前特訓 | 倒數天數、四個月訓練時間表、徒手版與健身房版菜單、打卡、教學影片、台灣室內滑雪場館 |
| 10 | 行前清單 | 從頭到腳的裝備圖（雙板／單板）、北海道與輕井澤五天行程範例 |

## 執行方式

這是純靜態網站，**不需要安裝、不需要建置**。

**方法一：直接開檔**

用瀏覽器開啟 `index.html` 就可以使用。

**方法二：本機伺服器（建議）**

部分瀏覽器對 `file://` 有限制，用本機伺服器比較穩：

```bash
# 用 Python（3.8 以上）
python3 -m http.server 8000

# 或用 Node.js（18 以上）
npx serve@14.2.4 .
```

然後打開 <http://localhost:8000>（`serve` 預設是 <http://localhost:3000>）。

**方法三：GitHub Pages**

1. 把整個資料夾推到 GitHub repository
2. 到 repository 的 **Settings → Pages**
3. Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`
4. 儲存後約一分鐘，網址會是 `https://<你的帳號>.github.io/<repository 名稱>/`

## 環境變數

**本專案不需要任何環境變數、API 金鑰或密碼。**

所有資料都寫在 `js/app.js` 裡，不會呼叫任何需要驗證的 API。`.env.example` 只是保留給未來擴充用（例如之後想串接匯率 API），目前裡面的變數都沒有被程式讀取。

## 資料儲存

- 「季前特訓」的打卡紀錄存在瀏覽器的 `localStorage`（key 以 `ski27-` 開頭），只存在使用者自己的瀏覽器，不會上傳。
- 其他設定（滑桿、天數等）重新整理後會回到預設值。

## 修改資料

雪場、交通、住宿的數字都在 `js/app.js` 開頭的 `R` 陣列裡，每座雪場一個物件：

```js
{
  id: 'rusutsu',          // 代號
  zh: '留壽都',            // 名稱
  lift: 16700,            // 一日券（日圓）
  liftOff: true,          // true = 官方公布價，false = 估算
  s: { beg:4, zh:5, ... },// 7 個條件的 1–5 分
  routes: [ ... ],        // 大阪出發的交通路線
  stay: { near:{...}, far:{...} }, // 住宿比較
  ...
}
```

旅費帳本用到的租借、課程、餐費單價在 `RENT`、`WEAR`、`LESSON`、`FOOD` 常數。

## 注意事項

- 價格、時刻、周遊券資訊查詢於 **2026 年 10 月 27 日**，出發前請以各官方網站為準。
- 標「估」的數字是估算值，標「官方」或「查詢」的是已公布或實際查到的價格。
- 插畫都是用程式繪製的原創圖，沒有使用網路照片。
- 資料來源見 [`docs/sources.md`](docs/sources.md)。
